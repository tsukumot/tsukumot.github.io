https://tsukumot.github.io/
This tool allows you to input notes to find chords.
Press and hold a button to also search for fractional chords using that note as the bass note.
It does not support tension chords (9th or higher).

Clicking a matched chord name plays the actual sound.
Playback uses just intonation only for major/minor thirds; all others use equal temperament.
It clearly shows how the impression changes based on the root note selection, even when the constituent notes are the same.
・For the 7th, since just intonation is rarely used in performance, it uses equal temperament.
・If the bass note is not included in the chord, it will be added for playback.

You can also change the note assigned to the top-left button via the query.
