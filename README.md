This tool allows you to input constituent notes to find chords (harmonies).
Long-pressing a button also searches for fractional chords using that note as the root.

Clicking a matched chord name plays its actual sound.
Playback uses just intonation only for major/minor thirds; all others use equal temperament.
It clearly shows how the choice of root note affects the impression, even with identical constituent notes.
・For 7th note, we've used equal temperament since just intonation is rarely chosen for performance. (Natural 7th support is planned)
・If the bass note isn't included in the chord, it will be added for playback.

You can also change the note assigned to the top-left button via the query.
