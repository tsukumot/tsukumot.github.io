構成音を入力して、コード（和音）を調べるためのツールです。
ボタンを長押しすると、その音をベース音とした分数コードについても検索します。
addコードには非対応です。

ヒットしたコード名をクリックすると実際の音が再生されます。
再生音は長3度/短3度のみ純正律、他は平均律としています。
構成音が同じでも、根音の選び方による印象の違いが分かりやすくなっています。
・7度に関しては、演奏で純正律を選択することがほぼないため平均律としました。（自然7度は対応予定）
・ベース音がコードに含まれていない場合、足した状態で再生されます。

また、クエリで左上ボタンに割り当てる音を変更できます。
